# 🎨 Color Palette Extractor

Automatically extract the **dominant colors** from any image and generate a neat color palette.

---

## 🔹 Features

* Extract **top N colors** using K-Means clustering
* Display colors as a **visual palette**
* Shows approximate **percentage of each color**
* Interactive **Gradio web interface**

---

## 🔹 Tech Stack

* Python
* OpenCV / NumPy
* scikit-learn (K-Means)
* Gradio

---

## 🔹 How to Run

```bash
pip install opencv-python numpy scikit-learn gradio
python app.py
```

Upload an image in the Gradio interface to see the **extracted color palette**.

---

## 🔹 Future Improvements

* Show **hex codes** of colors
* Export palette as **CSS or JSON**
* Multi-palette options for complex images
